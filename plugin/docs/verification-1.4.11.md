# 1.4.11 当前轮次与运行状态修复

> 代码与模拟宿主回归已通过；没有自动安装、重载插件或修改真实宿主聊天数据库。安装包为 `plugin/dist/local.diff-view-1.4.11.piplug`，本地目录安装请在插件页手动 reload。

## 修复行为

- 对话运行时，“最近一轮”按宿主当前用户任务 ID 选择并显示“本轮”。尚未修改文件时显示本轮空状态，不回退到上一轮内容；缺少当前捕获证据也不借用旧修改。
- 空闲时显示当前会话最近有修改的轮次。空轮次只保留运行标记，结束后移除，不留聊天正文。
- 历史导入接收当前任务 ID 与开始时间，不再仅用最后一条可见历史用户消息推断运行轮次；支持元数据先于 JSONL 落盘。
- 已有 Shell-only 主轮次即使没有原生修改事件，也按用户与最终回复证据结算。结算后的旧 inbox 版本不能重新打开它。
- 同会话、同项目且全部工具 ID 明确归属于同一用户时，可修正过期用户绑定并去重 Agent／原生记录；不按时间猜测合并，不重分配混合或不完整工具证据。子消息仍按明确父引用归属。
- 侧栏历史元数据在任务 ID／状态变化时刷新一次，避免旧 bootstrap 状态造成两个主轮次都显示运行中；文件列表与 diff 继续无闪屏轮询。
