# 1.4.2 临时会话记录与侧栏稳定性修复

> 本地目录构建更新后，需在 PI-Desktop 插件页手动 reload；包安装使用 `plugin/dist/local.diff-view-1.4.2.piplug`。本次不自动安装、重载、授权或改写宿主历史。

## 本次修复

| 现象 | 原因与修复 | 回归证据 |
| --- | --- | --- |
| 未打开工作区时临时文件更改被忽略 | 主进程只接受工作区 root、renderer 跳过无 root 证据。现在使用可信宿主契约确定本会话 scratch 叶目录，接收真实成功 Write/Edit 证据，并保留已验证历史字节 | `no-workspace-capture.test.ts`、`scratch-path.test.ts` |
| 空侧栏与复制菜单随轮询闪动 | 每次后台轮询都切换加载状态，复制按钮随之禁用；空状态有重复文案。现在保留当前内容，后台更新不切换首次加载状态，空状态只显示一次 | `sidebar-stability.spec.ts` 的空状态、菜单连续可用检查 |
| 点击文末卡片改变文件顺序 | `focusFileId` 把目标移到首位。现在只优先加载目标，保持首次记录顺序；超出单页的元数据按原顺序续载 | 256 文件性能与分页测试、卡片定位浏览器测试 |
| Git/会话切换慢、折叠状态重置 | 页签切换卸载审阅组件。现在保留两个面板的节点与状态；返回 Git 时静默核对数据，不清空页面或输入 | 页签往返节点同一性、折叠状态与主题回归 |
| 新增其他文件也重新加载当前差异 | 全局 review ID 变化失效所有差异缓存。现在按会话/轮次、文件版本、上下文和重试标识复用差异页；后台多页列表完成后再发布 | 未变化文件请求次数、节点同一性、滚动位置及分页更新检查 |

## 边界

- 无工作区记录仅提供历史查看和复制，不授予撤销、重新应用或任意磁盘写入权限；跨会话 scratch 叶目录、凭据、内部数据、遍历路径及链接/junction 仍受校验。
- 缺少可信宿主路径契约时不猜测根目录。缺失的 before/after 保持未知，不使用当前磁盘或 Git 状态补造历史。
- 文件顺序使用首次捕获/历史证据的记录顺序；历史没有可靠时间字段时不伪造时间。
- 浏览器检查使用实际生产面板 bundle 与模拟宿主桥接；本地 Git 浏览器回归另使用真实临时后端。未宣称已完成当前 PI-Desktop 原生窗口闪屏验收或用户旧记录重导入。
