1.4.35 的 src/git/local-management.ts 新增 commitFiles，并让 commitDiff 接受 path。提交通过不可变 OID 与第一父提交比较（根提交用空树），用 diff-tree --raw --numstat -z --no-renames 返回文件状态、模式与行数；历史路径做字面语法及敏感路径检查，树两侧仅允许 000000/100644/100755，阻止 symlink/submodule，不使用针对当前磁盘的 filePath/safeResolve 来决定历史文件是否存在。当前同名路径变为目录或已被删除不应阻挡历史查看。前端复用 GitPatch/useGitPreview，缓存及迟到响应按提交实例隔离；commitFiles 必须归入 transport.ts 的 gitReads，保留读并发和每秒6次限额。原整提交 commitDiff 兼容入口仍保留。
