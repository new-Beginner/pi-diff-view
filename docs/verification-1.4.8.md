# 1.4.8：侧边栏历史恢复稳定性

> 更新本地 `plugin/` 后需在插件页手动 reload；真正不存在的修改前内容不能凭 TS 扩展名、当前磁盘或 Git 内容恢复。

## 修复

- 整轮 Agent 快照的版本更新会覆盖原生历史已恢复的文件，导致行数、差异短暂退化。新增按文件的内部证据检查点：仅对完全相同的采集身份、工具证据、端点哈希、模式及不确定状态保留恢复结果。
- 新证据或端点改变照常导入并重新验证；保留原生独有路径和历史文件顺序，不屏蔽真实并发冲突或损坏快照。
- 新导入记录标记待恢复；主进程先导入、恢复，再返回会话侧边栏数据。不再等待下一次两秒恢复，也不在恢复之后再次导入半成品。
- 原生缓存清理后，匹配 Agent 记录也能复用插件保存的完整历史文本；此前该分支只检查独立的原生历史记录。
