# 1.4.14：修复跨轮次混入与旧运行记录残留

> 本地插件目录已构建；需在插件页重载 Diff view，或安装 `plugin/dist/local.diff-view-1.4.14.piplug`。没有自动安装或重载，没有改写真实宿主聊天记录。真实异常记录仅在临时副本上回放，不能替代重载后的客户端验收。

## 原因与最小修复

不是将开始和结束的行数简单相加，而是历史恢复把新采集记录的过期用户身份当成有效归属，复制了上一轮原生修改。混合后的工具证据阻止了正确重归属；同时每个用户只处理第一条匹配采集记录，另一条旧记录没有结算。

生产逻辑只修改 `src/core/host-history.ts`：

- 后续明确 USER 边界可以否定旧用户绑定，但不依靠时间接近猜测合并。
- 精确工具 ID 优先；已知归属冲突时不能回退使用旧用户身份。
- 对既有错误恢复，仅排除带 `hostRecovery.files` 标记、全部为原生证据且精确证明属于采集开始前另一轮的条目；保留原始、混合或未关联的采集证据。
- 将这些条目从错误轮次纠正后，用正确用户的历史证据恢复本轮；更换用户时清除旧回复绑定。
- 处理所有匹配采集记录，不再只结算第一条。保留原有 inbox 版本保护、哈希恢复、只读边界和记录 ID。

不修改 UI、Agent 采集、文件打开、Git、权限或依赖。保留工作区既有未提交修改。

1. 在当前对话结束后，在插件页重载本地 Diff view 目录，或安装新版包。
