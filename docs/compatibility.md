# 兼容性与 Codex 对照

目标宿主为 PI-Desktop **0.17.0**；依据同版本源码和 SDK，而非 0.18 beta 文档中尚未提供的接口。

## 功能对照

| Codex 桌面审查行为 | Diff view 设计与边界 |
|---|---|
| 未暂存、已暂存、提交、基准分支 | Git 原始内容对比；根提交与合并提交采用空树/第一父提交，基准分支采用 merge-base → HEAD |
| 最近一轮 | Write/Edit 的真实前后快照；另外提供已记录历史轮次选择，不补造安装前历史 |
| 仓库选择 | 宿主项目 roots 中的仓库；不扩大到授权目录之外的父仓库 |
| 统一/左右 diff、行号、增删统计 | 相同底层行差异算法，真实三行上下文、可扩展上下文和分页 |
| 行反馈 | 绑定范围和版本的 old/new 行锚点，失效后不自动挪到其他代码 |
| 文件/hunk 暂存或取消暂存 | 精确索引内容变更，保留工作区；有索引/工作区冲突则拒绝 |
| 撤销 | Git 未暂存文件/hunk 恢复，或完整已结算轮次的文件级回退/重新应用 |
| 批量操作 | 当前可见文件最多 20 个，逐文件重读版本、独立执行并显示结果；不宣称原子事务 |
| 最终回复文末变更卡片 | 官方 entryExtra 插槽；列本次任务净变更，点击文件打开本插件的右侧视图；输入区不注册按钮 |
| 提交、推送、PR 与模型自动审查 | 不纳入本插件；只生成用户可发送的审查请求，不自动调用模型 |

这是对已公开行为的实现，不是 Codex 官方插件，不承诺指定版本的像素级复制。

## 精准归因与历史

Agent hook 中的模型 `turn_start` 是内部迭代，不是用户回合；采集从 `before_agent_start` 开始，批准计划等没有这个事件的路径在首次受支持工具调用时建立采集记录。重试或不完整边界优先标为不完整，不擅自推断宿主 durable turnId。

0.17.0 回复插槽没有正式 turnId，Agent 原始消息 ID 也不同于 UI ID。entryExtra 会把任务内各条助手文本 trim 后以两个换行连接，插槽的时间与 ID 来自最后一条内容消息。新版仅从这段内容末尾的完整段落边界候选中精确匹配已结算的最终回复哈希，仍要求会话、时间和任务唯一性；不是包含关键词的模糊匹配。重复、无时间戳、运行中、边界不明、超出末尾匹配预算或旧版历史都不挂卡片。

工具结果迟到、外部编辑、未知工具或缺少快照会禁止依赖完整归因的恢复。Bash 和子代理不可靠归因；Git 未暂存视图包含 AI、用户和其他进程的全部可见修改。

不使用 `pi.session.listMessages` 读取普通聊天，不读取 SQLite 或安装前日志。侧栏跳转仅复用固定构建的 store.R 与插件页签工厂 aO；视图定位使用宿主现有 piViewOpen / view:open 通道传递插件内存选择令牌，无原生审阅 DOM 操作。

## 特殊文件与 Git

凭据、依赖和内部路径不预览或导出。二进制、2 MiB 以上文件、symlink/junction、submodule、Git 冲突和只有 mode 变化的记录有专门状态，不当作普通文本处理。

Git 操作使用固定 argv、NUL 分隔路径和 literal pathspec；不拼 shell、不调用 external diff/textconv、不执行 reset --hard、clean、stash 或远程操作。无法安全表示的状态以禁用操作和说明替代。

Git 重命名只支持整文件索引暂存/取消暂存；不提供重命名 hunk 或工作区移动撤销。未暂存移动仅配对唯一且字节完全相同的源/目标；编辑后移动可能显示为删除和新增。轮次移动也以两条真实路径生命周期展示，可单独或批量确认恢复。

审查文件元数据最多 100 个/~32 KiB，正文每页最多 100 行/~30 KiB（界面默认 80 行）；评论列表最多 100 条/~28 KiB，过长反馈拒绝回填。未暂存超限文件和子模块采用保守元数据，可能显示未发生实际内容变化的条目；均不可写操作。单行超过桥接预览预算时明确显示提示，而不是截断后冒充完整代码。

重操作通过 jobStart/jobPoll 执行，每个短请求共享限速队列，写操作不自动重试。2 秒 renderer 超时与 64 KiB 合并请求/响应限制已核对。文末卡片不再调用 openLayer，未知宿主构建拒绝侧栏跳转，绝不回退到居中窗口；Git 独立视图保留。

0.17.0 import map 只含 `react`、`react-dom`、`react-dom/client`，**不含 react/jsx-runtime**。聊天 renderer 使用经典 JSX并覆盖该入口的 tsconfig；构建检查禁止其他外部模块，浏览器回归直接加载最终 ESM 产物。插件主进程 ready 不代表 renderer 就绪，启动阶段存储为插件私有诊断，不采集聊天内容。

宿主 session:turnEnded 没有 captureRunId/时间戳，仅触发 inbox 导入并记录审计，不据此猜测回合绑定。POSIX 权限保留与 FIFO 防阻塞实现存在，但本次本机为 Windows，未宣称 Linux/macOS 原生兼容验证通过。

## 原生授权与生命周期

开发目录 hot reload 不扩大权限。首次完整集成版必须由你在插件页显式重新加载并批准新的 Agent/renderer 权限。

销毁插件时释放计时器、renderer 注册、样式和审查层；locator 仅由所属 generation 删除。持久快照/评论保留至清理历史。历史清理必须先停止活跃采集。

## 工作区外记录

只采集受支持 Write/Edit 明确指定的普通路径；before/after 先后绑定同一工具调用和用户任务，首次 before 与最终 after 合并。外部记录展示绝对路径和只读来源标记，不授予父目录访问或恢复权限。凭据、应用私有数据、依赖目录、UNC/设备/ADS 与链接祖先拒绝采集；大文件、二进制、缺失内容保持元数据状态。摘要总数覆盖全部净变更，文件元数据分页最多 100 项/28 KiB，不把 Git 全部未提交改动混入任务卡片。
